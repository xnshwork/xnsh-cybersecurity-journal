# xnsh | Cybersecurity Learning Journal

A personal journey into cybersecurity, focused on developing practical skills through hands-on labs, technical investigation, and real-world security concepts.

## About

This repository documents my exploration of cybersecurity, from networking and Linux fundamentals to web application penetration testing, digital forensics, and threat detection.

The objective is to understand how systems work, how security weaknesses arise, and how to investigate, test, and secure them using practical techniques and open-source tools.

The repository serves as a collection of learning notes, experiments, lab reports, technical observations, and security projects.

## Documentation

Each technical investigation aims to include:

- **Objective:** The purpose of the experiment
- **Concepts:** Relevant technical background
- **Environment:** Tools and configurations used
- **Methodology:** Commands and steps performed
- **Evidence:** Screenshots, outputs and observations
- **Analysis:** Interpretation of the results
- **Troubleshooting:** Problems encountered and their solutions
- **Conclusion:** Findings and lessons learned

The focus is on producing clear, reproducible, and technically accurate documentation.

## Ethics & Responsible Security Research

All security testing is conducted within authorized environments, personal systems, or intentionally vulnerable training applications.

The objective is to develop practical security knowledge while respecting privacy, legal boundaries, and responsible disclosure principles.

## Goal

To develop a strong foundation in cybersecurity, gain practical experience with industry-relevant tools, and build the technical skills required for web application penetration testing, digital forensic investigation, and security research.
